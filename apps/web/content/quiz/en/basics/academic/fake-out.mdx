question: Which of the following is true about the physical move Fake Out?
options:
  - "Makes the target flinch. This move fails unless it is the first move used by the user after it enters a battle."
  - "It guarantees a flinch but causes the user to take recoil damage."
  - "It strikes first, but fails if the target selected a status move."
  - "If used on the first turn, it knocks off the target's held item."
correctAnswerIndex: 0
reviewed: true
---

【Explanation】
The correct answer is "Makes the target flinch. This move fails unless it is the first move used by the user after it enters a battle."

Fake Out has a high priority (+3) and a 100% chance to make the target flinch. It can only be selected on the very first turn the user enters the battlefield; on subsequent turns, the move cannot even be chosen. It does not cause recoil damage to the user. It will hit regardless of whether the opponent selected an attack or a status move, unlike Sucker Punch which fails if the opponent isn't attacking. Finally, Fake Out does not remove held items, which is the effect of Knock Off.
