【Explanation】
The correct answer is "Badly poisons the target. If the user is a Poison type this move will never miss.".

Toxic inflicts the "badly poisoned" status condition, where the damage increases each turn, starting from 1/16 of the target's maximum HP. This is different from the regular "poisoned" condition caused by moves like Poison Powder, which deals a flat 1/8 HP damage every turn. Toxic is a status move and deals no direct damage, unlike Poison Fang, and it does not apply secondary effects like confusion.
