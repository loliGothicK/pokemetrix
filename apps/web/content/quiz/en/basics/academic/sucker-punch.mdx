[Explanation]
"Sucker Punch" is a priority +1 move, but it will only succeed if the target has selected an attacking move during that turn.
It is not restricted to the first turn like "Fake Out", nor does it gain power when the opponent switches like "Pursuit". It will fail if the opponent selects a status move, making it a move that requires good prediction.
