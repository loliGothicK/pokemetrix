[Explanation]
"Bullet Punch" is a Steel-type physical move that has +1 priority, allowing the user to strike first regardless of Speed.
Although it has "Punch" in its name, it is not a Fighting-type move like the similar priority move "Mach Punch". It is also not a move that goes last like "Avalanche", nor does it bypass protection moves like "Feint".
