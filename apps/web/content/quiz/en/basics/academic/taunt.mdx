question: What is the correct effect of the "Taunt" status condition?
options:
  - The affected Pokémon cannot use status moves for 3 turns.
  - Raises the target's Attack by 2 stages and confuses them.
  - Forces the target to only use attacking moves targeting the user.
  - Prevents the target from using the same move twice in a row.
correctAnswer: The affected Pokémon cannot use status moves for 3 turns.
reviewed: true

【Explanation】
The correct answer is "The affected Pokémon cannot use status moves for 3 turns.".

Taunt restricts the target to only using attacking moves, rendering setup moves, healing, and other status moves completely unusable for a few turns. It does not raise the target's Attack and confuse them; that is the effect of Swagger. It also doesn't force the opponent to attack the user (like Follow Me or Rage Powder do), nor does it prevent the consecutive use of the same move (which is Torment).
