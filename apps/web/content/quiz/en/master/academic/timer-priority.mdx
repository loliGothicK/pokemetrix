  When both "Your Time" (Player Timer) and the overall match timer expire
  simultaneously, the Player Timer expiration takes priority, resulting in an
  immediate loss with no TOD judgment (Pokémon count / HP%) applied.

【Explanation】
The overall match timer takes priority over the Player Timer.
If both expire at the same moment, the result is processed as an overall match timer expiration — not an immediate loss from the Player Timer — and the TOD judgment (Pokémon count → HP% → HP total) determines the winner.
