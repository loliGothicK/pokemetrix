question: "What are the correct multipliers for the Same Type Attack Bonus (STAB) when Terastallized? (When the original type and Tera Type are different / When they are the same)"
options:
  - "Different: 1.5x / Same: 2.0x"
  - "Different: 2.0x / Same: 2.0x"
  - "Different: 1.3x / Same: 1.5x"
  - "Only the Tera Type gets STAB, and the original type loses its boost"
correctAnswer: "Different: 1.5x / Same: 2.0x"
---

When Terastallized, you receive STAB for both your original types and your Tera Type. Tera Type moves get a 1.5x multiplier. If the original type and the Tera Type are the same (Terastallizing into a type you already have), the multiplier for moves of that type increases from the usual 1.5x to 2.0x.
