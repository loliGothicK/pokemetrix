question: >-
  Ally Pokémon A with the Ability "Prankster" uses "Encore" on Ally Pokémon B,
  while Opponent Pokémon C uses "Sucker Punch" on Pokémon B. Pokémon B used a
  status move on the previous turn, but selected an attacking move this turn. If
  the action order is A (Encore) -> C (Sucker Punch) -> B, what happens to
  "Sucker Punch"?
options:
  - It succeeds and deals damage to Pokémon B.
  - It fails because the move Pokémon B will use was changed to a status move.
  - >-
    It fails because Pokémon B is considered to have already acted upon
    receiving Encore.
  - >-
    It succeeds, but the damage is nullified because Pokémon B can no longer use
    an attacking move.
correctAnswerIndex: 0
reviewed: true
---

【Explanation】
The success of "Sucker Punch" is determined by the move the target selected during command input, not the move it ultimately executes.
Therefore, even if the target is forced to use a status move due to "Encore," "Sucker Punch" will still succeed and deal damage as long as the target originally selected an attacking move at the start of the turn.
