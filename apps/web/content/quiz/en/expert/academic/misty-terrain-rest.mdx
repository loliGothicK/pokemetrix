  When 'Misty Terrain' is active, what happens if a grounded Pokémon uses the
  move 'Rest'?
options:
  - It fully restores HP and falls asleep normally.
  - It fully restores HP but does not fall asleep.
  - 'Misty Terrain blocks it, causing the move to fail.'
  - Misty Terrain is cleared from the field.

【Explanation】
Misty Terrain protects grounded Pokémon from non-volatile status conditions. Because Rest inflicts the user with sleep, Misty Terrain blocks the status, causing the move to fail entirely without healing.
