  Pokémon A uses 'Parting Shot' on Pokémon B, which has the Ability 'Magic
  Bounce'. Which of the following describes the correct outcome of this
  interaction?

  - "Pokémon A's stats are lowered, and Pokémon A switches out."
  - "Pokémon B's stats are lowered, and Pokémon B switches out."
  - >-
    The move is reflected, but fails because forced-switching moves cannot be
    reflected.
correctAnswerIndex: 0

【Explanation】
When 'Parting Shot' is reflected by 'Magic Bounce', the Pokémon with Magic Bounce (Pokémon B) becomes the user of the move. It targets the original user (Pokémon A), lowering Pokémon A's Attack and Special Attack. Then, because Pokémon B is now the user of Parting Shot, Pokémon B is the one forced to switch out. This is a common and powerful tactic in VGC to force an opponent's Magic Bounce Pokémon (like Hatterene) off the field.
