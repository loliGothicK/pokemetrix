【Explanation】
The priority brackets for each move are as follows:

1. **Protect**: Priority +4
2. **Fake Out**: Priority +3
3. **Extreme Speed**: Priority +2
4. **Quick Attack**: Priority +1

When moves have the same priority, the Pokémon with the higher Speed acts first. However, when priorities differ, the move with the higher priority will always execute first regardless of Speed.
