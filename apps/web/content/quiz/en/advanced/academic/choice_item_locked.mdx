question: "When does a Pokémon holding a 'Choice Band', 'Choice Specs', or 'Choice Scarf' become locked into using only one move?"
options:
  - "After using a move once"
  - "Immediately when the battle starts (before using a move)"
  - "After using the same move twice"
  - "After its HP drops below half"
correctAnswer: "After using a move once"
---

A Pokémon holding a Choice item can only select the move it used from the moment it uses a move once. The lock is removed by switching out. Any move can be chosen on the first turn of battle.
