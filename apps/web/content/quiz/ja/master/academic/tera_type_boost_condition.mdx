question: "テラスタルした場合のタイプ一致補正（STAB）の倍率として正しいものはどれですか？（元のタイプとテラスタルタイプが異なる場合 / 一致する場合）"
options:
  - "異なる場合: 1.5倍 / 一致する場合: 2.0倍"
  - "異なる場合: 2.0倍 / 一致する場合: 2.0倍"
  - "異なる場合: 1.3倍 / 一致する場合: 1.5倍"
  - "テラスタルタイプのみが一致補正を受け、元のタイプには補正がつかなくなる"
correctAnswer: "異なる場合: 1.5倍 / 一致する場合: 2.0倍"
---

テラスタル時は元のタイプとテラスタルタイプの両方で一致補正を受けられます。テラスタルタイプの技は1.5倍。元のタイプとテラスタルタイプが一致する場合（同タイプでテラスタル）、その技は通常の1.5倍より高い2.0倍になります。
