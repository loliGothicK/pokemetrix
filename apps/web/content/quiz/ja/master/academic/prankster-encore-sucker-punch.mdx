question: >-
  味方のポケモンAが特性「いたずらごころ」で味方のポケモンBに「アンコール」を使用し、相手のポケモンCがポケモンBに「ふいうち」を使用した。
  ポケモンBは前のターンに変化技を使用しており、このターンは攻撃技を選択した。 行動順が A(アンコール) → C(ふいうち) → B
  の順だった場合、「ふいうち」の処理はどうなるか？
options:
  - 成功し、ポケモンBにダメージを与える
  - ポケモンBが出す技が変化技に変更されたため、失敗する
  - ポケモンBはアンコールを受けた時点で行動済みと判定されるため、失敗する
  - 成功するが、ポケモンBが攻撃技を出せなくなったためダメージは無効化される
correctAnswerIndex: 0
reviewed: true

【解説】
「ふいうち」の成功判定は、対象が実際に使用する技ではなく「コマンド入力時に選択した技」を参照して行われます。
そのため、「アンコール」によって強制的に使用する技が変化技に変更されたとしても、ターン開始時に攻撃技を選択していれば「ふいうち」は成功し、ダメージを与えます。
