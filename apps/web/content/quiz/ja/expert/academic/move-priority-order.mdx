  - しんそく

correctOrderIndices:
  - 1
  - 3
  - 2
  - 0
reviewed: true

【解説】
各技の優先度は以下の通りです。

1. **まもる**: 優先度 +4
2. **ねこだまし**: 優先度 +3
3. **しんそく**: 優先度 +2
4. **でんこうせっか**: 優先度 +1

同じ優先度の場合は素早さが高い方が先に行動しますが、優先度が異なる場合は素早さに関係なく優先度が高い技が必ず先に発動します。
