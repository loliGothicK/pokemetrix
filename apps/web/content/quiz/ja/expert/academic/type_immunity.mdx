question: "ゴーストタイプのポケモンが完全に無効化できる（効果がない）技のタイプの組み合わせはどれですか？"
options:
  - "ノーマル と かくとう"
  - "どく と むし"
  - "ノーマル と エスパー"
  - "かくとう と じめん"
correctAnswer: "ノーマル と かくとう"
---

ゴーストタイプのポケモンは、「ノーマル」タイプと「かくとう」タイプの技を完全に無効化します。むしやどくは半減であり、エスパーを無効化するのはあくタイプです。
