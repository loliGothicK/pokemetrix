question: あくタイプの先制技「ふいうち」が成功する条件として正しいものはどれか？
options:
  - 相手が攻撃を選んでおりかつこの技を使ったターン中、まだ攻撃をしていない時でないと失敗する。
  - 場に出て最初のターンである
  - 相手がそのターンに「変化技」を選択している
  - 相手がそのターンに交代しようとしている
correctAnswerIndex: 0
reviewed: true

【解説】
「ふいうち」は優先度+1の先制技ですが、相手がそのターンに「攻撃技」を選択していないと失敗してしまいます。
「ねこだまし」のように場に出た最初のターンしか使えないわけではなく、「おいうち」のように交代時に威力が上がる技でもありません。相手が変化技（補助技）を選択していた場合も失敗となるため、使い所が重要です。
