## Overview

Battle Analytics is a tool that visualizes your win rates and behavioral trends based on the data saved in your Battle Records.
It provides two main views: Winrate Insights and a Custom Dashboard.

## Winrate Insights

The **Winrate Insights** tab allows you to quickly check your overall battle data for the season.

### Displayed Metrics

| Metric          | Description                                                      |
| --------------- | ---------------------------------------------------------------- |
| Total Matches   | The total number of games played in the season                   |
| Win Rate        | Calculated as Wins / (Wins + Losses)                             |
| Common Matchups | The Pokémon that appeared most frequently on the opponent's team |

## Dashboard

The Dashboard allows you to build your own custom analytics view by freely placing widgets.
For detailed instructions and widget types, please refer to the [Dashboard](/docs/dashboard) documentation.
