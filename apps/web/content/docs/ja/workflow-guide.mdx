## 概要

Pokemetrix は、ポケモンの対戦準備から試合の振り返り、そして勝率向上に向けたチーム改善までを一貫してサポートする統合対戦ツールです。

このガイドでは、以下のコアサイクルを実際に対戦で回すための具体的な手順を解説します。

```text
[1. チーム構築] ───> [2. 対戦記録] ───> [3. データ分析] ───> [4. チーム改善]
  チームビルダー          対戦記録入力         勝率分析/ダッシュボード    努力値・技の再調整
```

---

## Step 1: チームビルダーでチームを管理する

まずは対戦で使用するチームを [チームビルダー](/docs/team-builder) で作成・登録します。

### 1. チームの新規作成

1. ナビゲーションメニューから **「チーム管理」** を開きます。
2. 画面上部の **「新規作成」** ボタンをクリックすると、空のチームが作成されます。
3. チーム名（例: `Champions Season 1` など）を入力します。ここで設定した名前は、後ほど対戦記録を入力する際の選択肢として表示されます。
4. 既に対戦用テキスト（Pokepaste 形式）をお持ちの場合は、**「インポート」** から Pokepaste の URL またはテキストを貼り付けることで一括読み込みも可能です。

### 2. ポケモンの登録と基本設定

1. 6つのスロットのいずれかをクリックすると、ポケモン選択ダイアログが開きます。
2. 名前やタイプで検索してポケモンを選択します。
3. 詳細設定パネルで以下の項目を設定します。
   - **持ち物**
   - **特性**
   - **性格**
   - **技（最大4つ）**: 技選択ドロワーからタイプ・威力・命中・優先度を確認して登録します。
   - **メガシンカ**: メガシンカ可能なポケモンは「メガシンカ」ボタンでフォルムチェンジを適用できます。

### 3. 努力値（EVs）の設定と耐久調整

- **努力値上限ルール**:
  - Pokémon Champions 形式では、各ステータスの上限は **32**、6ステータスの合計上限は **66** に制限されています。上限を超える入力は自動で制御されます。
- **耐久調整ツール (Survival Tuning)**:
  - 努力値タブの「耐久調整」ボタンをクリックすると、仮想敵の攻撃を耐えるための努力値を自動計算するモーダルが開きます。
  - 仮想敵のポケモン・技・性格・持ち物・天候・リフレクター/ひかりのかべなどを指定し、「確定耐え」や「最高乱数切り耐え」に必要な HP・防御・特防の最適配分を1クリックで適用できます。

### 4. チームの保存

- ログイン中の場合、作成・変更したチームは自動的にクラウドに同期されます。
- 画面右上の **「保存」** ボタンで現在の状態を確実に保存しておきましょう。

## Step 2: 対戦を記録する (Battle Record)

ランクマッチなどの対戦を行ったら、[対戦記録](/docs/battle-record) 画面で試合結果と選出を記録します。

### 1. シーズンの準備

対戦記録は「シーズン」単位で集計・管理されます。

1. サイドバーまたは画面上部の **「新規シーズン」** をクリックします。
2. シーズン名、フォーマット（**シングル** / **ダブル**）、レギュレーション、期間を設定して作成します。

### 2. 対戦記録フォームの起動

- シーズンを選択した状態で、**「対戦を記録」** ボタンをクリックします。
- デスクトップ環境では、キーボードの **`N`** キーを押すだけでも即座に記録フォームを開くことができます。

### 3. 自チームの紐付けと選出入力

1. **チームの選択**:
   - フォーム上部の「自チーム」ドロップダウンから、Step 1 で作成したチームを選択します。登録されているメンバー6体が自動的に表示されます。
2. **選出の記録**:
   - 各ポケモンのカードをクリック（またはタップ）することで、選出ステータスが循環します。
     - **未選出**（通常表示）
     - **後発**（青枠 + 青インジケーター）
     - **先発**（黄枠 + 黄インジケーター）
   - ダブルバトルの場合、先発2体・後発2体（合計4体）の選出ルールに沿って現在の選択数がヘッダーに表示されます。

### 4. 相手チームと相手選出の記録

1. **相手ポケモンの追加**:
   - 空きスロット（`+` アイコン）をクリックし、相手パーティのポケモン（最大6体）を検索して追加します。
2. **相手の選出ステータス**:
   - 自チーム同様、相手のカードをクリックして **先発（黄）** / **後発（青）** / **選出外** を指定します。
3. **詳細情報の追記 (持ち物・特性・技)**:
   - 相手カードにマウスを重ねると表示される鉛筆アイコン（モバイルでは常時表示）をクリックすると、「相手ポケモンの詳細」ダイアログが開きます。
   - 対戦中に判明した相手の持ち物、特性、技、立ち回りメモを記録しておくと、後の分析で貴重な情報になります。

### 5. 勝敗・レート・タグ・メモの記録

- **勝敗**:
  - 「WIN」「LOSS」「DRAW」のボタンをクリックするか、キーボードの **`W`**、**`L`**、**`D`** キーを押して選択します。
- **対戦後レート**:
  - 対戦後の最新レート（例: `1650`）を入力します。直前の対戦からのレート増減（`+16` など）が自動的に算出されます。
- **タグ付け**:
  - 相手の構築タイプや主要ギミック（例: `trick-room` (トリックルーム)、`tailwind` (おいかぜ)、`weather-rain` (雨)、`intimidate` (威嚇サイクル) など）をタグ付けできます。独自のカスタムタグも入力可能です。
- **対戦メモ**:
  - 勝因・敗因、相手の想定外の技構成、プレイングの反省点などを自由に記述します。
- **保存**:
  - **`Ctrl + S`**（Macは **`Cmd + S`**）を押すか、右下の **「保存」** ボタンをクリックして記録を完了します。

## Step 3: データを閲覧・分析して振り返る

対戦データを記録していくと、蓄積された記録から自身のプレイング傾向やチームの強み・弱みを多角的に確認できます。

### 1. 対戦記録一覧 (`/battle-record`) での直近確認

- シーズン内の対戦が時系列でカード表示されます。
- 上部のサマリーバーで、現在のレート、直前の試合からの増減、シーズン通算勝率、総試合数（W/L/Dの内訳バー）を確認できます。
- **フィルター機能**: 「すべて」「勝ち」「負け」「引き分け」のタブで絞り込みが可能です。
- 各対戦カードをクリックすると、当時の選出、相手のパーティ構成、詳細メモをいつでも確認・編集できます。

### 2. 勝率分析 (`/battle-analytics`) での環境分析

画面上部の **「勝率分析」** ボタンをクリックすると、シーズン全体のマクロな統計画面へ移動します。

- **総合サマリー**: 総対戦数、通算勝率、勝利数、敗戦数がハイライト表示されます。
- **対面ポケモン別成績 (Top Opponents)**:
  - 相手チームに最も多く登場したポケモンがランキング形式で表示されます。
  - 各ポケモンに対する勝率プログレスバーと「〇勝 〇敗 〇分」の内訳が表示されるため、「環境で何が多く、どのポケモンに負け越しているか」を一目で把握できます。

### 3. ダッシュボード (`/dashboard`) でのカスタム分析

PC（デスクトップ）環境では、さらに高度な BI ツールである **ダッシュボード** を利用できます。
ウィジェットを自由に配置・カスタマイズして、知りたい切り口の分析ビューを構築できます。

| ウィジェットテンプレート       | 得られる分析インサイト                                                               |
| ------------------------------ | ------------------------------------------------------------------------------------ |
| **勝率サマリー**               | 現在の通算勝率を一目で把握                                                           |
| **先発 / 後発 成績**           | 先発に置いたポケモンごとの勝率を比較し、最も安定する初手を特定                       |
| **先発相性表 (Pivot Heatmap)** | 自軍先発 vs 相手先発の組み合わせごとの勝率をヒートマップで可視化                     |
| **勝敗要因ブレイクダウン**     | 相手パーティに含まれていた特定のポケモンやタグ（ギミック）が勝率に与えた影響度を算出 |
| **レート推移**                 | 試合ごとのレート推移を折れ線グラフで確認し、好調期・不調期の波を分析                 |
| **直近の試合 / ストリーク**    | 直近10試合の結果や、現在の連勝・連敗数を表示                                         |

- **変数の活用**: 変数バーにシーズン切り替えドロップダウンを配置することで、同じレイアウトのまま複数シーズンのデータを瞬時に比較できます。

---

## Step 4: 分析をもとにチームを改善する

データ分析によって課題が明確になったら、再び **チームビルダー** に戻り改善を行います。

1. **苦手ポケモンの対策**:
   - 勝敗要因ブレイクダウンや Top Opponents で勝率が極端に低い相手が判明した場合、そのポケモンに有利な技や持ち物への変更、または補完枠のポケモンの採用を検討します。
2. **耐久ラインの再調整**:
   - 対戦メモや振り返りで「相手の特定技で確定1発を取られて崩された」ケースを確認したら、チームビルダーの「耐久調整」モーダルでその技を指定し、耐えられる努力値配分へアップデートします。
3. **選出パターンの確立**:
   - 先発相性表や先発成績で高い勝率を記録している組み合わせを基本選出パターンとして確立し、対戦メモに基本選出ルールとしてストックします。

このサイクルを繰り返すことで、感覚だけに頼らないデータドリブンなチーム強化と勝率向上が実現できます。
