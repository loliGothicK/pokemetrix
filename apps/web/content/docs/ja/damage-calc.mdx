## 概要

ダメージ計算機は、攻撃側・防御側のポケモンと技を指定して、ダメージ範囲・KO 確率を計算するツールです。
フィールド条件や壁・天候なども考慮した精密な計算が可能です。

## 基本的な使い方

1. **攻撃側のポケモン** を選択する
2. **技** を選択する
3. **防御側のポケモン** を選択する
4. ダメージ範囲と KO 確率が自動的に表示される

## 攻撃側・防御側の設定

各サイドで以下の設定が可能です。

| 項目         | 説明                              |
| ------------ | --------------------------------- |
| ポケモン     | 対象のポケモン（名前で検索）      |
| 努力値（EV） | 各ステータスの努力値（0〜32）     |
| 性格         | ステータス補正のかかる性格        |
| 持ち物       | タイプ強化アイテム・Choice 系など |
| 特性         | 計算に影響する特性                |
| ランク補正   | -6〜+6 のランク変化               |
| 状態異常     | やけど・まひなど                  |

## フィールド条件

「フィールド」タブから以下の条件を設定できます。

### 天候

- 晴れ / 雨 / 雪 / 砂嵐

### フィールド

- エレキ / グラス / ミスト / サイコ

### 壁・その他

- リフレクター / ひかりのかべ / オーロラベール
- てだすけ / じゅうでん / フェアリーオーラ など

## ダメージ結果の見方

計算結果には以下の情報が表示されます。

- **ダメージ範囲**: 最低〜最大ダメージ（実数値）
- **HP割合**: 最低〜最大の HP 割合（%）
- **KO 確率**: 確定1発 / 乱数1発 / 確定2発 など
- **ダメージロール**: 16段階のすべてのロール値

## ダブルバトル設定

画面上部のトグルで **「シングル / ダブル」** を切り替えられます。
ダブル設定では全体技のダメージ補正（0.75倍）が適用されます。
