## 概要

マイ BOX は、育成済みのポケモンを個別に保存・管理できるストレージです。
チームに依存しない形でポケモンを登録しておくことで、複数のチームで同じポケモンを再利用できます。

## BOX へのポケモン保存

チームビルダーで設定したポケモンのスロットを開き、**「BOX に保存」** ボタンをクリックすることで BOX に登録されます。
持ち物・特性・性格・技・努力値がすべて一緒に保存されます。

## BOX からの読み込み

チームビルダーの空きスロットから検索ダイアログを開くと、BOX に保存済みのポケモンが候補として表示されます。
選択するとそのポケモンの全設定が一括でスロットに適用されます。

## 検索・絞り込み

BOX 画面の上部にある検索バーでポケモン名を入力して絞り込みができます。

- 名前の一部で検索（例: `カイリュー`）
- 日本語・英語どちらでも検索可能

## ポケモンの削除

各ポケモンカードの **「BOX から削除」** ボタンをクリックすると BOX から削除されます。
チームに登録されているポケモンには影響しません。

## ログインとデータ同期

ログインしている場合、BOX のデータはクラウドに保存されます。
ログインしていない場合はブラウザのローカルストレージに保存されます。
