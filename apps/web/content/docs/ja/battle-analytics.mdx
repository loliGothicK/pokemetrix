## 概要

勝率分析（バトル分析）は、対戦記録のデータをもとに勝率・傾向を可視化するツールです。
蓄積されたデータから環境の傾向や苦手な相手を把握し、チーム改善へ繋げることができます。
チーム構築から対戦記録、データ閲覧までの全体像は [実践ワークフローガイド](/docs/workflow-guide) を参照してください。

## 勝率分析

**「勝率分析」** では、シーズンの対戦データをすばやく確認できます。

### 表示される指標

| 指標           | 説明                                   |
| -------------- | -------------------------------------- |
| 総対戦数       | シーズン全体の試合数                   |
| 勝率           | 勝ち / (勝ち + 負け) で算出            |
| 対面の多い相手 | 相手パーティに最も多く登場したポケモン |

## ダッシュボード

ダッシュボードでは、ウィジェットを自由に配置して独自の分析画面を作成できます。
詳細な使い方やウィジェットの種類については、[ダッシュボード](/docs/dashboard) のドキュメントを参照してください。
