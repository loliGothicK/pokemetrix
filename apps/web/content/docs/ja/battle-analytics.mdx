## 概要

バトル分析は、対戦記録のデータをもとに勝率・傾向を可視化するツールです。
勝率インサイトとカスタムダッシュボードの2つのビューを提供します。

## 勝率インサイト

**「Winrate Insights」** では、シーズンの対戦データをすばやく確認できます。

### 表示される指標

| 指標 | 説明 |
|---|---|
| 総対戦数 | シーズン全体の試合数 |
| 勝率 | 勝ち / (勝ち + 負け) で算出 |
| 対面の多い相手 | 相手パーティに最も多く登場したポケモン |

## ダッシュボード

> ダッシュボードはデスクトップ環境（PC）でのみ利用可能です。

**「Dashboard」** では、ウィジェットを自由に配置してカスタム分析画面を作れます。

### ウィジェットの種類

| ウィジェット | 説明 |
|---|---|
| **Win Rate Summary** | 勝率を1つの数値で表示 |
| **Result Breakdown** | 勝・負・引分の内訳 |
| **Leads Analysis** | 先発ポケモンごとの勝率 |
| **Rating History** | 試合ごとのレート推移グラフ |
| **Peak Rating** | シーズン最高レート |
| **Recent Matches** | 直近10試合 |
| **Current Streak** | 現在の連勝 / 連敗ストリーク |
| **Matchup Heatmap** | 先発 vs 相手先発の勝率ヒートマップ |
| **Win/Loss Causes** | 相手ポケモンの勝敗への影響度 |

### ウィジェットの追加

1. ダッシュボードを編集モードにする（「Edit」ボタン）
2. **「ウィジェットを追加」** をクリック
3. ウィジェット種別を選択
4. データソース（シーズンまたは変数）を設定
5. Visualize タブでグラフ種別を選択

### 変数（Variable）

変数を使うと、ドロップダウンでシーズンを切り替えてウィジェット全体を更新できます。
複数シーズンの比較に便利です。

### Transformer

Transformer を使うと、SQLクエリの結果をカスタム変換してグラフに渡すことができます。

| Transformer | 説明 |
|---|---|
| None | そのまま渡す |
| Win Rate | 勝率を計算 |
| Streak | 連勝ストリークを計算 |
| Leads Win Rate | 先発ごとの勝率 |
| Rating Diff | レート変動を追加 |
| Matchup Pivot | 先発相性ピボットテーブル |
| Win/Loss Causes | 勝敗要因分析 |

## ダッシュボードの保存と共有

ダッシュボードはクラウドに保存されます（ログイン必須）。
複数のダッシュボードを作成し、デフォルトを設定することもできます。
