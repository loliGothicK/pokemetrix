## 概要

対戦記録は、ポケモン対戦の結果を試合ごとに記録・管理するためのツールです。
シーズン単位で管理でき、相手チームや選出、メモなども一緒に保存できます。

## シーズンの作成

対戦記録を開始するには、まず **シーズン** を作成する必要があります。

1. サイドバーの **「新規シーズン」** をクリック
2. シーズン名・フォーマット（シングル / ダブル）・レギュレーション・期間を設定
3. 「保存」で作成完了

## 対戦の記録

シーズンを選択した状態で **「対戦を記録」** ボタンをクリックするとフォームが開きます。

### 記録できる情報

| 項目         | 説明                                                       |
| ------------ | ---------------------------------------------------------- |
| 勝敗         | 勝ち / 負け / 引き分け                                     |
| 自分のチーム | 使用したチームを選択                                       |
| 選出         | 各ポケモンの役割（後発 / 先発 / 選出外）をタップで切り替え |
| 相手チーム   | 相手のパーティを登録（特性・持ち物・技も記録可）           |
| レート       | 対戦後のレート                                             |
| メモ         | 重要な立ち回り・脅威・読みなどを自由記述                   |
| タグ         | ギミック・アーキタイプなどの分類タグ                       |

### 選出の記録

チームパネルで各ポケモンをタップすると、選出状態を切り替えられます。
（`選出外` → `後発` → `先発` → `選出外` ... の順にトグルします）

## 対戦記録の一覧

シーズンごとに対戦記録が一覧表示されます。
各記録をクリックすると詳細・編集が可能です。

## 記録の削除

各対戦記録の削除ボタンから削除できます。この操作は取り消せません。

## ログインとデータ同期

ログインしている場合、対戦記録はクラウドに保存されます。
複数デバイスからアクセスする場合は、ログインを推奨します。
