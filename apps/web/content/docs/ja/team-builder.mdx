## 概要

チームビルダーは、競技対戦用のポケモンチームを構築・管理するためのツールです。
最大6体のポケモンを1チームに登録し、持ち物・特性・技・努力値を細かく設定できます。

## チームの作成

サイドバーの **「チーム管理」** を開き、画面上部の **「New」** ボタンをクリックすると新しいチームが作成されます。
チーム名は任意のタイミングで編集可能です。

## ポケモンの追加

空きスロットをクリックすると検索ダイアログが開きます。

- 名前で検索（例: `ガブリアス`）
- タイプでフィルタ（例: `@type:ドラゴン`）

ポケモンを選択するとスロットに追加され、詳細設定パネルが表示されます。

## 基本設定

### 持ち物・特性・性格

各スロットの詳細パネルから **持ち物**・**特性**・**性格** を設定します。
メガシンカが可能なポケモンは「メガシンカ」ボタンでフォルムチェンジできます。

### 技の選択

「技を選択」ボタンを最大4回クリックして技を設定します。
技ドロワーでは威力・命中・タイプ・優先度などの詳細が確認できます。

## 努力値（EV）の設定

「努力値」タブから各ステータスの努力値を設定します（各ステータスの上限は 32 です）。
上限（66）を超える入力ができないように設計されており、残り努力値はリアルタイムで更新されます。

## インポート / エクスポート

| 操作                             | 説明                                               |
| -------------------------------- | -------------------------------------------------- |
| **Pokepaste URL からインポート** | Pokepaste の URL を貼り付けてチームを読み込む      |
| **テキストからインポート**       | Pokepaste 形式のテキストを直接貼り付けてインポート |
| **クリップボードにコピー**       | チームを Pokepaste 形式でコピー                    |
| **Pokepaste を作成**             | Pokepaste サイトにチームを投稿してリンクを取得     |

## チームの保存と共有

ログイン状態であれば自動的にサーバーと同期され、どのデバイスからでも最新のチームにアクセスできます。ログインしていない場合はブラウザのローカルストレージに保存されます。

## チームのシェア

チーム詳細画面の **「チームを共有」** ボタンから共有リンクを生成できます。
ステータス・努力値を含めるかどうか選択可能です。
